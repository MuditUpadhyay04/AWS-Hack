# Pathfinder — 3-minute demo walkthrough

A tight shot list for the submission video (max 3 min). Aim for ~5 beats.
Have the dev server (or the deployed URL) open, and ideally the **real backend
connected** (set `VITE_API_BASE_URL`) so the questions and roadmap are genuinely
generated by Qdrant, not the mock.

## Before recording
- [ ] Backend reachable; `VITE_API_BASE_URL` set (confirm a real question comes back).
- [ ] ElevenLabs keys set (`VITE_ELEVENLABS_*`) so questions are spoken — use Chrome (Web Speech for voice answers).
- [ ] Sound on. Browser zoom ~100%. Pre-write nothing; type live.

## The 5 beats

**1. The blank page (0:00–0:20)**
Open on just the notepad. "You open Pathfinder and just start writing about whatever you're trying to figure out." Start typing a goal, e.g.:
```
Investment
- want to pay off ~$20k student loans
- start investing a little
- not sure where to start
```
As you type, the left **cortex** panel wakes up and the **"{domain} mode"** badge appears in the top bar — "it's already understanding the domain."

**2. It structures your thoughts (0:20–0:40)**
Point at the **"what i'm understanding"** preview turning the notes into structured JSON. Toggle `</> json` for one second: "this is exactly what we feed the vector search." (Optional: open plug-ins → connect Google Sheets.)

**3. The voice-powered interview (0:40–1:30)**
Click **build my roadmap**. Pathfinder *speaks* a clarifying question. Answer by voice (mic) or typing. It asks one or two more — "these aren't random; Qdrant picks the question that best separates the likely paths." Mention the constraint chips appearing ("things it now knows about you").

**4. The roadmap + the Qdrant payoff (1:30–2:15)**
The hand-drawn roadmap sketches in. Call out the **rationale pill**: *"84% of N similar people succeeded on this path"* — "that's vector search over real outcomes, not a guess." Hover a node to show the tooltip with concrete next-actions. Point at the orange **risk** node. (If Sheets is connected, wait for a sync pulse to show the roadmap react live.)

**5. Play your path (2:15–3:00)**
Click **keep going →**. Pathfinder says "let's play this out" and the roadmap becomes a **playable world** — same JSON, each step a level, the risk a hazard. Close on the one-liner: "Your plan isn't a static list — it's something you can read, hear, and play."

## Backup / if something fails
- No backend? It falls back to the mock automatically — the flow still works (just say the data is mocked).
- No mic/voice? Type the answers; everything still proceeds.
